Guia Rápido de Bancada para o Eletricista

1. Teste de Resistência da Bobina Com multímetro na escala de Ohms (Ω), meça os 2 fios da bobina. A resistência esperada fica entre 8Ω e 16Ω. Se der 0Ω (curto) ou infinito (aberta), a bobina está queimada.
2. Borne do Relé (CUIDADO) Ligue SEMPRE no borne NO (Normalmente Aberto). Se ligar no NC (Fechado), a trava ficará acionada o tempo todo e queimará o solenóide em poucos minutos por superaquecimento.
3. Diodo de Proteção (Flyback) Recomendado soldar um diodo 1N4007 em paralelo com os fios da bobina (faixa branca no positivo). Ele absorve o pico de tensão reversa na hora do desarmamento.
4. Isolamento da Placa O ESP32 e o Relé possuem trilhas e soldas expostas na parte inferior. Fixe-os em placa de acrílico ou caixinha plástica para não encostar na carcaça de ferro.

Passo 1: Alimentação AC & Ponto de Energia

Preparar a chegada de energia no pedestal da catraca

Padrão Elétrico: A catraca precisa de 2 pontos de tomada padrão NBR 14136 internamente.
  • Puxar fiação 110V/220V até a base Passar Fase, Neutro e Terra via eletroduto ou canaleta até o interior do pedestal da catraca.
  • Instalar Régua de Tomadas (2 posições) Fixar a régua no interior. Tomada 1 para Fonte 12V 2A AcBel e Tomada 2 para Carregador 5V USB do ESP32.
  • Conectar o Terra (Verde/Amarelo) no Chassi Metálico Parafusar terminal olhal no chassi da catraca para escoamento de estática e proteção.
2

Passo 2: Limpeza Mecânica & Teste Direto 12V

Testar a bobina e o travamento mecânico antes da eletrônica

  • Limpeza do Mecanismo Dentado e Mancal Remover teias, graxa endurecida e poeira acumulada na parte superior do cabeçote Henry.
  • Lubrificação com Grafite Seco Aplicar pó de grafite no pino de retenção e trava. Não usar óleo denso que grude sujeira.
  • Teste Direto na Fonte 12V (Disparo Manual) Encostar os 2 fios do solenóide diretamente na saída da fonte AcBel. O pino DEVE retrair com um "clac" forte e permitir o giro com a mão. Ao soltar, a mola deve travar imediatamente.

Passo 4: Firmware C++ & Gravação no ESP32

Código completo para carregar via Arduino IDE

firmware/esp32_catraca/esp32_catraca.ino 
/*
 * =========================================================================
 * BJ SPORTS - FIRMWARE DE CONTROLE DE CATRACA INTELIGENTE
 * Placa: ESP32-WROOM-32 DevKit
 * =========================================================================
 */
#include <WiFi.h>
#include <WebServer.h>

// >>> CONFIGURE O WI-FI DA RECEPÇÃO AQUI <<<
const char* ssid = "BJ_SPORTS_RECEPCAO";
const char* password = "senha_wifi_aqui";

const int PIN_RELE = 4;        // GPIO 4 -> Pino IN do Módulo Relé
const int PIN_LED = 2;         // LED indicador azul embutido no ESP32
const int TEMPO_PULSO_MS = 1000; // 1 Segundo de destravamento mecânico

WebServer server(80);

void acionarCatraca() {
  Serial.println("[CATRACA] -> Pulso elétrico disparado! Destravando...");
  digitalWrite(PIN_RELE, LOW);   // Módulo relé ativa em nível LOW (0V)
  digitalWrite(PIN_LED, HIGH);   // Acende LED azul de confirmação
  delay(TEMPO_PULSO_MS);
  digitalWrite(PIN_RELE, HIGH);  // Trava novamente
  digitalWrite(PIN_LED, LOW);
  Serial.println("[CATRACA] -> Trava rearmada com sucesso.");
}

void handleStatus() {
  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.send(200, "application/json", "{\"status\":\"ONLINE\",\"device\":\"ESP32-WROOM-32\",\"gym\":\"BJ Sports\"}");
}

void handleLiberar() {
  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.sendHeader("Access-Control-Allow-Methods", "GET,POST,OPTIONS");
  acionarCatraca();
  server.send(200, "application/json", "{\"success\":true,\"message\":\"Catraca liberada com sucesso!\"}");
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_RELE, OUTPUT);
  pinMode(PIN_LED, OUTPUT);
  
  // Inicia com a trava armada (relé desligado)
  digitalWrite(PIN_RELE, HIGH);
  digitalWrite(PIN_LED, LOW);

  WiFi.mode(WIFI_STA);
  WiFi.begin(ssid, password);
  Serial.print("Conectando ao Wi-Fi BJ Sports");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\n[WIFI] Conectado! Endereco IP: http://" + WiFi.localIP().toString());

  server.on("/", HTTP_GET, handleStatus);
  server.on("/status", HTTP_GET, handleStatus);
  server.on("/liberar", HTTP_GET, handleLiberar);
  server.on("/liberar", HTTP_POST, handleLiberar);
  server.begin();
  Serial.println("[HTTP] Servidor Web da Catraca operando na porta 80.");
}

void loop() {
  server.handleClient();
}
  • Configurar Nome e Senha do Wi-Fi Ajustar as constantes ssid e password no código antes de gravar.
  • Gravar no ESP32 via Arduino IDE Placa: "ESP32 Dev Module", Porta COM correspondente, Velocidade 115200.
  • Teste de Pulso via Celular/Navegador Abrir http://<IP_DO_ESP32>/liberar no navegador do celular conectado no mesmo Wi-Fi.

Passo 5: Acomodação Mecânica, Cablagem & Teste Final

Organizar os fios para máxima durabilidade contra vibrações

  • Fixar ESP32 e Relé em Base Plástica / Fita Dupla Face Forte Garantir isolamento total contra o chassi metálico da coluna.
  • Amarrar Chicotes com Abraçadeiras Plásticas (Enforca-gato) Prender a fiação longe do disco dentado giratório para evitar que enrosque nos giros.
  • Teste de Carga / 20 Giros Consecutivos Disparar o comando 20 vezes consecutivas girando os braços para validar fluidez e estabilidade térmica.
